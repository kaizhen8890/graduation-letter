# 毕业祝福页

NFC 毕业祝福页面，使用 GitHub Pages 部署。

- 站点：https://kaizhen8890.github.io/graduation-letter/
- 本地替换说明：见仓库内的 assets/fonts 授权说明与页面顶部注释。

页面结构：
- index.html：网页主体（轻量版，引用 assets/）
- assets/bgm.m4a：背景音乐（AAC 128kbps）
- assets/bgm.mp3：兼容备用
- assets/letter.webp：结尾手写信纸照片
- assets/jacket.webp：旧版封面小唱片（当前页面未使用）
- assets/fonts/：内嵌圆体的 OFL 授权与说明
